### 1. Interface development stages

| Platform | Interface name | Characteristics |
|-----------|----------------|-----------------|
| **8.0, 8.1** | **Simple interface** | Uncomfortable, each element is programmed separately |
| **8.2** | **Managed interface** | Uses the platform's standard tools, created with little or no programming |
| **8.3** | **"Taxi" interface** | Single-window workflow, modern, covered in the course |

---

### 2. Details of each interface

#### 2.1. Simple interface (8.0, 8.1)

```
Features:
├── Main menu (list of commands)
├── Toolbar (small, unclear icons)
└── Each element programmed separately (labor-intensive)

Example: 1C:Accounting 8, edition 2.0
└── A nice appearance can be achieved, but it's difficult
```

#### 2.2. Managed interface (8.2)
```
Advantages:
├── Sections panel
├── Commands in the navigation panel
└── All elements are created with platform tools
    (no programming required)

Example: 1C:Accounting 8, edition 3.0
└── Widely used, still in use today
```

#### 2.3. "Taxi" interface (8.3)
```
New features:
├── All operations in a single window
├── Fast switching between sections
├── Opening document lists
├── Switching between opened windows
└── Closing unnecessary windows

Covered in the course → the most modern solution
```

---

### 3. Backward compatibility

| Platform | Available interfaces |
|-----------|----------------------|
| 8.2 | Managed + Simple |
| 8.3 | Taxi + Managed + Simple |

> **Important:** If necessary, configurations for older interfaces can be created on the new platform.

---

### 4. Adoption status

- **Currently widespread:** Managed interface and Simple interface
- **Future trend:** "Taxi" interface (actively developing)
- **Course focus:** "Taxi" interface (the most modern and convenient)
