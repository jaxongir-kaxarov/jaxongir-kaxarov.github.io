## 3. Main differences of the three objects

## 3.1 Константы

**Константа** is the **simplest object**.

Properties:

* stores only **a single value**
* this value is **set by the user**
* if necessary the value can be retrieved via **встроенный язык**
* that is, can be used from **program code**

For example:

**наименование организации**

---

## 3.2 Перечисления

**Перечисления** are a **list of predefined values**.

Properties:

* values are created in **Конфигуратор**
* the user **cannot add new values**
* the list is **defined by the developer**

For example:

**типы товаров**

values:

* **товар**
* **услуга**
* **работа**
* **возвратная тара**

---

## 3.3 Справочники

**Справочник** is the **most flexible object**.

Properties:

* the user **can create new items**
* can create **группы**
* if the справочник is **иерархический**
  elements are placed inside groups
* items can be **deleted**

That is:

the user **is given freedom**.

---

## 4. Справочник capabilities

With **Справочник** items you can perform the following actions:

* create a new **элемент**
* create a **группа**
* move items to **another group**
* delete items (**удаление**)
* remove items from the **информационная база**
