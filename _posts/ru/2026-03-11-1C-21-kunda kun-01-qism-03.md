### 1. История версий 1C:Enterprise

| Версия | Год | Статус |
|--------|-----|--------|
| 7.7 | 1999 | Устарела (прошлый век) |
| 8.0, 8.1 | 2000-е | Мало используется |
| **8.2** | | Широко распространена |
| **8.3** | | Наиболее современная, **рекомендуемая для изучения** |

> Преимущество версии 8.3: возможность работы с мобильными устройствами Android и iOS.

---

### 2. Этапы установки платформы

#### 2.1. Загрузка
- **Адрес:** v8.1c.ru
- **Путь:** Главное меню → Методическое сопровождение → Учебная версия
- **Условие:** заполнение анкеты в онлайн-магазине (Ф.И.О. + email)
- **Результат:** на email приходит ссылка для скачивания

#### 2.2. Распаковка архива
- Большой по размеру архив — процесс займёт много времени
- Файлы распаковываются в папку

#### 2.3. Способы установки

| Способ | Описание |
|--------|---------|
| Полная автоматическая | Устанавливаются все компоненты |
| **Выборочная установка** | **Выбор необходимых компонентов** |
| Ручная установка | Программное обеспечение из папки "platform" |

> В курсе выбран метод **выборочной установки** — установлена только платформа.

#### 2.4. Настройки установки
- Каталог установки: по умолчанию (C:\Program Files\1cv8)
- Языки интерфейса: все языки или выбранные
- **Выбран:** только русский язык

---

### 3. Запуск программы

**Путь:** Пуск → Все программы → 1C:Enterprise 8.3 (Учебная версия)

**Первое окно:** Список баз данных
- Пока пусто
- На следующих уроках будет создана первая база данных

---

### Основной вывод

Учебная версия бесплатна, представляет собой полнофункциональную платформу для обучения и тестирования. Установка простая, но требует времени. Основная работа начинается с создания базы данных.
