## 📄 Краткое описание

В этом уроке создаётся новый справочник **Номенклатура** и добавляются дополнительные **реквизиты**.

**Номенклатура** — это список **товаров**, которые предприятие покупает и продаёт. Внутри этого справочника для хранения дополнительной информации о товаре создаются новые поля, например **Описание товара** и **основной поставщик**.

В ходе урока показано, как через вкладку **данные** добавить новые **реквизиты**, выбрать для них **тип данных** и как в **пользовательском режиме** использовать эти данные.

---

## 📚 Полный конспект

## 1. Создание нового справочника

Мы создаём новый **справочник**.

Это будет список **товаров**, то есть:

* приобретаемых
* продаваемых

товаров.

Такой список обычно называется:

**Номенклатура**

### Этап создания

#### 1️⃣ Нажимается кнопка **добавить**

#### 2️⃣ Вводится название:

**Номенклатура**

---

## 2. Дополнительные поля (реквизиты)

В справочнике **Номенклатура** нужно хранить дополнительные данные.

Например:

* описание товара
* основной поставщик

Для этого создаются **реквизиты**.

Порядок действий:

### 1️⃣ Открывается вкладка **данные**

### 2️⃣ Добавляется новый **реквизит**

---

## 3. Реквизит: Описание товара

Первый реквизит:

**ОписаниеТовара**

### Правило именования

В поле **имя**:

* пробелы не допускаются
* специальные символы не допускаются

Разрешены только:

* буквы
* цифры
* символ **_**

Например:

**Номенклатура**

Но в поле **синоним** можно записать любой текст:

**Список товаров**

Именно это увидит пользователь.

### Важное отличие

| Поле        | Кто использует |
| ----------- | --------------- |
| **имя**     | разработчик     |
| **синоним** | пользователь    |

При написании кода разработчик обращается именно по **имени**.

---

## 4. Выбор типа данных

Для каждого **реквизита** указывается **тип данных**.

Для **Описание товара** выбирается:

**тип данных → строка**

По умолчанию длина:

**10 символов**

Это очень мало.

Варианты:

* увеличить длину до **100**
* или включить **неограниченная длина**

Правильный вариант:

✅ **неограниченная длина**

Тогда пользователь сможет вводить текст любой длины.

---

## 5. Второй реквизит: основной поставщик

Создаётся новый реквизит:

**ОсновнойПоставщик**

Здесь между словами не ставится пробел.

При вводе и нажатии Enter система автоматически формирует **синоним**:

**Основной поставщик**

Это происходит потому, что второе слово начинается с заглавной буквы.

---

## 6. Выбор типа данных

Для этого реквизита требуется другой тип данных.

В окне выбора **Тип данных** доступны следующие варианты:

### Примитивные типы

* **число**
* **дата**
* **булево**

Тип **булево** принимает только два значения:

* **истина**
* **ложь**

Чаще всего он отображается в виде флажка.

---

### Ссылочный тип данных

Нам нужен вариант:

**справочник ссылка**

Потому что в качестве **основного поставщика** выбирается элемент из справочника **контрагенты**.

Соответственно:

**тип данных → справочник ссылка контрагенты**

То есть реквизит содержит ссылку на элемент справочника **контрагенты**.

```md
СправочникСсылка.Контрагенты
```

---

## 🛠 Пользовательский режим

Теперь запускаем систему.

### 1️⃣ Нажимаем **F5**

### 2️⃣ Сохраняем **конфигурацию базы данных**

В интерфейсе появится новое меню:

**список товаров**

Это и есть справочник:

**Номенклатура**

Пользователь увидит именно **синоним**.

---

## 7. Создание нового товара

Пример:

```md
Cтол обеденный
```

### Описание

Поле **Описание товара**, например:

```md
Длина = 120 см, высота = 70 см
```

---

## 8. Выбор основного поставщика

В поле **основной поставщик** есть специальная кнопка.

При нажатии:

* показываются наиболее часто используемые элементы
* если нужного нет — нажать **показать все**

Откроется список **контрагенты**.

Например выбирается:

**поставщики → Мебель опт ООО**

---

## 9. Возможности ссылочного реквизита

У таких реквизитов есть ещё одна кнопка:

**открыть**

С её помощью выбранный **контрагент** можно сразу открыть для **редактирования**.

---

## 10. Создание ещё одного товара

Второй элемент:

```md
Cтол журнальный
```

### Описание

```md
Cтекло
```

### Поставщик

Ранее выбранный:

**Мебель опт ООО**

Система предложит его автоматически.

Причина: система запоминает выборы пользователя.

---

## 11. Процесс сохранения

При сохранении элемента система показывает:

* всплывающее окно

В этом окне пользователь может:

* снова открыть элемент
* или продолжить работу
