### 6. MAIN CONCEPTS AND TERMS

#### 6.1. DIRECTORY (Spravochnik / Reference)

| Attribute | Description |
|-----------|-------------|
| **Definition** | A list of objects of the same type |
| **Purpose** | Store and reuse data |
| **Example** | Lists of products, employees, customers, warehouses |

**User capabilities:**
- Add new entries (e.g., a new product)
- Use stored data in documents

#### 6.2. DOCUMENT

| Attribute | Description |
|-----------|-------------|
| **Definition** | An operation carried out in the company |
| **Example** | Purchase of goods, sale of goods, inter-warehouse transfer |

**Document structure:**
```
DOCUMENT CREATION PROCESS:

1. Create a new document (e.g., sale of goods)
2. Select data from directories:
   ├─ Select a customer
   ├─ Select a product
   ├─ Select a warehouse
   └─ Select an organization
3. Save the document
```

#### 6.3. DOCUMENT STATUSES

| Status | Definition | Result |
|--------|------------|--------|
| **Save (Record)** | The document is saved as a draft | The system does not change |
| **Post (Confirm)** | The document is confirmed/posted | The system changes |

**Results of posting (confirming) a document:**

- ✅ Goods are removed from the warehouse
- ✅ Sales profit is recorded
- ✅ Customer debt is recorded

> **Conclusion:** Only a posted (confirmed) document has effect. A saved document is only a draft.
