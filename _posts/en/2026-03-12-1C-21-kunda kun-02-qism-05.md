## 1. What are иерархические справочники?

**Справочники** can sometimes be **иерархическими**.

This means:

* data is not in a simple **linear list** form
* but organized using **группы**.

This system is similar to folders and files in **проводник**:

* **группы** → folders
* **элементы** → files

Elements are placed inside a specific group.

---

## 2. Why are иерархические справочники needed?

Such справочники are used to organize large volumes of data.

For example:

The **номенклатура** list can sometimes have **several thousand items**.

If items are divided into groups:

* the user finds the needed item faster
* navigation becomes easier
* data stays organized

Also:

The nesting of **группы вложенность** (nested groups) can be unlimited.

## 🛠 Practical section

## 1. Create a Новый справочник

We will create a new справочник named **Контрагенты**.

This справочник will include:

* **Поставщики**
* **Покупатели**
* **банки**
* other organizations (for example **налоговая инспекция**)

### Naming rule

**Справочники** are usually written in the **plural form**:

* **Контрагенты**
* **Склады**
* **Организации**

But **документы** are written in the **singular form**:

* **Поступление товаров**
* **Реализация товаров**
* **Перемещение товаров**

---

## 2. Enable Иерархия

To make a справочник **иерархический**:

### 1️⃣ open the **окно редактирования объекта**

### 2️⃣ go to the **иерархия** tab

### 3️⃣ check the **иерархический справочник** option

---

## 3. Launch the Конфигурацию

Then start the system:

### 1️⃣ press **F 5**

### 2️⃣ the system will prompt to update the **конфигурацию базы данных**

Then the following window appears:

* **реорганизация информации**

This window indicates:

* the database structure has changed
* a new object was added or modified

To save:

press the **принять** button.

After that **пользовательский режим** starts.

---

## 📂 Creating groups

Now we will create groups inside the **Контрагенты** справочник.

A new command appears:

**Создать группу**

For example:

* **Поставщики**
* **Покупатели**

### Shortcuts

* **Ctrl + F9** → **создать группу**
* **Insert** → **создать элемент**

---

## 👥 Adding elements

You can create elements inside each group.

### Покупатели group

For example:

```md
Мебель розница ООО
```

This company can be our **Покупатель**.

---

### Поставщики group

For example:

```md
Мебель опт ООО
```

This company is considered a **Поставщик**.

---

## ⚠️ Fixing a mistake

If an element was added to the wrong group, it can be moved.

### Method 1 — Context menu

#### 1️⃣ right-click the element

#### 2️⃣ select **переместить в группу**

#### 3️⃣ choose the desired group

---

### Method 2 — Edit the element

#### 1️⃣ double click the element

#### 2️⃣ change the **родитель** field

#### 3️⃣ press **записать и закрыть**

As a result the element moves to the new group.
