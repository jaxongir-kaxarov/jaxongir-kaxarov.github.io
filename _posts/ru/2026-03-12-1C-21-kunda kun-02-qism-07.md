## 1. Что такое Перечисления?

**Перечисления** — это объект конфигурации, который хранит список заранее определённых значений.

Этот список:

* создаётся в **Конфигураторе**
* пользователь не может его **изменять**
* нельзя добавлять новые значения пользователем

---

## 2. Различие между Перечислениями и Справочником

| Свойство                      | **перечисления**     | **справочник**     |
| ---------------------------- | -------------------- | ------------------ |
| Где создаются значения       | **Конфигуратор**     | пользователь       |
| Добавление новых элементов   | невозможно           | возможно           |
| Количество элементов         | строго задано        | не ограничено      |

Поэтому:

* **перечисления** → для небольших и постоянных списков  
* **справочник** → для изменяемых и больших списков

---

## 3. Создание нового перечисления

Теперь в **Конфигураторе** создадим новое **перечисление**.

### Шаги

* 1️⃣ Перейти в раздел **перечисления**
* 2️⃣ Создать новый элемент
* 3️⃣ Ввести имя:

```md
ТипыТоваров
```

---

## 4. Ввод значений

Далее на вкладке **Данные** создаются **допустимые значения**.

Например:

* **Товар**
* **Услуга**
* **Работа**
* **ВозвратнаяТара**

Таким образом формируется список **ТипыТоваров**.

Эти значения:

* строго фиксированные
* заранее определённые

---

## 5. Использование перечислений

Чаще всего **перечисления** используются в качестве **типа данных** реквизитов.

Например: в справочнике **Номенклатура**.

---

## 6. Создание нового реквизита

Теперь в справочнике **Номенклатура** создадим новый реквизит.

На этот раз воспользуемся другим способом.

Ранее мы работали через:

**окно редактирования объекта**

Теперь будем работать через:

**дерево конфигурации**

### Шаги

* 1️⃣ Открыть справочник **Номенклатура**
* 2️⃣ Выбрать раздел **Реквизиты**
* 3️⃣ Добавить новый реквизит

Имя реквизита:

```md
ТипТовара
```

---

## 7. Выбор типа данных

Теперь для этого реквизита выбирается **тип данных**.

Откроется окно **Выбор типа**.

Здесь выбираем:

**перечисление ссылка ТипыТоваров**

Это означает, что значение реквизита будет выбрано из перечисления **ТипыТоваров**.

---

## 🛠 Пользовательский режим

Запускаем систему:

* 1️⃣ Нажать **F5**
* 2️⃣ Открыть **пользовательский режим**

---

## 8. Список товаров

Далее открывается раздел:

**Список товаров** — то есть **Номенклатура**.

---

## 9. Выбор типа товара

Для каждого товара можно выбрать:

**ТипТовара**

Например:

| Товар            | Тип товара |
| ---------------- | ---------- |
| стол обеденный   | товар      |
| стол журнальный  | товар      |

При необходимости можно выбрать и другие значения:

* **услуга**
* **работа**
* **возвратная тара**
