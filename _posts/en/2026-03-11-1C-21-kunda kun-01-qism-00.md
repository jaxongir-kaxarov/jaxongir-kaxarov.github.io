# MODULE 1: CORE OBJECTS OF THE PLATFORM

## 1C:Enterprise 8 platform

---

### 1. MODULE OVERVIEW

| Parameter | Description |
|----------:|------------|
| Module number | Module 1 (1/6) |
| Duration | 5 days |
| Platform version | 1C:Enterprise 8 |
| Level | Beginner (starts with the simplest objects) |

---

### 2. MODULE GOAL

Learn and practically create the platform's core objects:

- Step-by-step progression from simple to more complex objects
- Create a new information database (infobase)
- Create and configure objects used by end users

---

### 3. OBJECTS TO BE LEARNED

| № | Object name | Description |
|---:|-------------|------------|
| 1 | **Catalog** (Spravochnik) | Object for storing and managing data |
| 2 | **Enumeration** (Perechisleniye) | List of limited values |
| 3 | **Constant** | Store constant values |
| 4 | **Document** (Dokument) | Records operations and transactions |
| 5 | **Accumulation register** (Registr nakopleniya) | Inventory and exchange accounting |
| 6 | **Information register** (Registr svedeniy) | Stores periodic data |

---

### 4. PRACTICAL TASKS

```
MODULE PLAN (5 days)

Day 1: Introduction to the platform + Create a new infobase
       └─ Familiarization with the simplest concepts

Day 2-3: Catalogs (Spravochniki)
         Enumerations
         Constants
         └─ Create and configure objects

Day 4: Documents
       └─ Create document forms

Day 5: Registers
       ├─ Accumulation registers
       ├─ Information registers
       └─ Ensure formation of movements (transactions)
```

---

### 5. MODULE OUTCOME

**Will be created:**

- ✅ New information database
- ✅ Working catalog system
- ✅ Documents and their linkage with registers
- ✅ Basic accounting mechanism

**Will be mastered:**

- Practical skills with the platform's most important objects
- Understanding relationships between objects
