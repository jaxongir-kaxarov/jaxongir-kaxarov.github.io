## 1. What are Справочники?

**Справочник** — is a list of data of the same type.

For example:

* **сотрудники** list
* **клиенты** list
* **банки** list
* **товары** list

Справочники are also called:

* **классификаторы**
* **нормативно-справочная информация**
* **справочная информация**

---

## 2. Why are Справочники needed?

Справочники serve two main purposes.

### 1️⃣ Store data in one place

All lists are kept in one place and are organized within the system.

### 2️⃣ Accurately identify objects

For example, a company buys products from a **поставщик мебели**.

If there are no **справочники**:

* one user may write **стол обеденный**
* another user may write **стол обеденый**

As a result, the system treats these as **two different goods**.

In reality this is the **same product**.

Therefore **справочники** are needed to store objects **consistently and uniquely**.

---

## 3. How it works

In practice it works like this:

1. First data is entered into a **справочник**
2. Later, when working with documents the user **does not type the data**
3. Instead the user **selects from the list**

This:

* reduces errors
* standardizes data

## 🛠 Practical part

## 1. Create a Новый справочник

A справочник named **склады** is created in the configuration.

To do this:

### 1️⃣ Open **Конфигуратор**

### 2️⃣ Go to the **справочники** section

### 3️⃣ Click the **добавить** button

### 4️⃣ Enter the name **склады**

As a result, a new справочник is created.

---

## 2. Run the system

To check the new object, start the system.

### 1️⃣ Press **F5**

### 2️⃣ The system starts in **пользовательский режим**

After that a new command appears in the menu:

**склады**

---

## 3. Create справочник elements

You can add elements inside the **склады** справочник.

For example:

* **основной склад** — main warehouse
* **нижний склад (подвал)** — basement warehouse

Now when creating a document the user selects the required **склад** from the list.

---

## 4. Add a new element

If a new warehouse appears during operations:

* open the **склады** справочник
* add a new element

This does not cause any problems for the system.

---

## 📌 Important concepts

### 1️⃣ Справочник element

Each entry in a Справочник is called an:

**элемент справочника**

This is sometimes also called:

**объект информационной базы**

---

### 2️⃣ Object in Конфигуратор

The **склады** справочник we created is an:

**объект конфигурации**

---

✅ In short:

* **Справочник** — a list of data
* **элемент справочника** — an entry in the list
* **объект конфигурации** — an object created in Конфигуратор
