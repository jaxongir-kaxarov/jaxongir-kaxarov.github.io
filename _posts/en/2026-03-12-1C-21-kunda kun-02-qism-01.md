### 1. Training context

- **Day:** 2
- **Topic:** 1C programming
- **Main task:** Create a new database (DB)

### 2. Database concept

| Component | Definition |
|-----------|------------|
| **Data** | Information entered by the user during work processes |
| **Configuration** | The part that defines the main logic (what objects exist and how they relate) |

### 3. What does the configuration include?

- 📁 **Catalogs** (data lists)
- 📝 **Documents** (recording operations)
- 📊 **Reports** (data analysis)

### 4. Practical task

- **Goal:** Develop a custom configuration for a trading company
- **Today's plans:**
  - Enrich the configuration with new objects
  - Create catalogs
  - Create enumerations (enumeration types)
  - Create constants
  - Get familiar with these objects

### 5. Key concepts

| Object | Short description |
|--------|-------------------|
| **Configuration** | The program's structure and logic |
| **Catalog** | Persistent lists in the database |
| **Enumeration** | A set of limited values |
| **Constant** | Immutable values used across the application |

---

**Summary:** In today's lesson, participants learn how to create a new database in the 1C configurator, add the necessary objects, and develop a custom configuration for a trading company.
