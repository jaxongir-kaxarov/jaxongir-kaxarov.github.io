### 1. Automation object

| Parameter | Details |
|----------|----------|
| **Company name** | "Mebel Dom" |
| **Activity** | Furniture retail |
| **Legal form** | LLC — one legal entity |
| **Warehouses** | Multiple warehouses available |

---

### 2. Core business processes

#### 2.1. Goods receipt (procurement)

| Parameter | Description |
|----------|--------|
| **Source** | From suppliers |
| **Location** | Can arrive to different warehouses |
| **Accounting** | Quantity + **cost price** |
| **Financial result** | Liability to the supplier or prepayment |

#### 2.2. Goods sale (realization)

| Parameter | Description |
|----------|--------|
| **Process** | Shipment of goods to the client |
| **Accounting** | Quantity + **sale price** |
| **Condition** | Sale price > Cost price |
| **Warehouse** | Goods are issued from a warehouse |
| **Financial result** | Client's debt or payment (immediate or on credit — e.g., within 1 month) |

---

### 3. Financial flows

```
┌────────────────────┐        ┌──────────────────────┐
│  SUPPLIER          │ ←────→ │   COMPANY (us)       │
│  (debt or payment) │        │  (goods receipt)     │
└────────────────────┘        └──────────────────────┘
                                       ↓
                              ┌──────────────────────┐
                              │  WAREHOUSE (multiple)│
                              │  (quantity + cost)   │
                              └──────────────────────┘
                                       ↓
┌────────────────────┐        ┌─────────────────────┐
│     CLIENT         │ ←────→ │   COMPANY (us)      │
│ (debt or payment)  │        │   (goods sale)      │
└────────────────────┘        └─────────────────────┘
```

---

### 4. Mandatory checks and constraints

| Check | Description |
|-------|-------------|
| **Warehouse balance** | At sale time, verify whether the requested quantity exists in the warehouse |
| **Error message** | If the goods are insufficient — show a diagnostic message |
| **Purpose:** | Prevent negative balances |

---

### 5. Reporting system (mandatory)

| Report | Metrics |
|--------|---------|
| **Inventory report** | Quantity of goods in each warehouse |
| **Cost price report** | Cost value of goods in the warehouse |
| **Profit report** | **Main metric:** Sales amount − Cost price = **Profit** |
