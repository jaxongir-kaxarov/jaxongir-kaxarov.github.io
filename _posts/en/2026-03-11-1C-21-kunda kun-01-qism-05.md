### 1C:Accounting 8 — Installation and Setup

#### Step 1: Install the template configuration

Source of distribution:

- Archive downloaded from online1c.ru

Installation methods:

| Method | Description |
|--------|-------------|
| **Autorun** | Automatic installation menu |
| **Manual** | `Accounting` folder → `setup.exe` |

Process:

- 1C:Accounting 8.3 files are copied to the designated directory
- This process is called **"installing the template configuration"**

---

#### Step 2: Launch the platform

OS security prompt:

- Windows: "Was the application installed correctly?"
- Answer: **"Yes"** (no problem)

Version selection:

| Available version | Description |
|-------------------|-------------|
| 8.2 | Older version |
| **8.3** | **"1C:Enterprise Training Version"** ← Selected |

---

#### Step 3: Create the information database

Initial state:

- The list of databases is empty
- The system prompts to add a new database

Types of database creation:

| Type | Description |
|------|-------------|
| **New (empty)** | Clean, without any data |
| **From template** | Based on a prepared configuration |

Template selection:

- "1C:Accounting for enterprises" → "Training version"
- **Demo database** (with prepared data) ← Selected

Settings:

- Name: Standard name (not changed)
- Folder: Installation location (can be changed if needed)

Creation process:

- Click "Next" → "Finish"
- A special file is created (stores database data)

---

#### Step 4: Log into the system

Appears in the database list:

- "1C:Accounting for enterprises. Training version"

Start:

- "1C:Enterprise" button (user mode)

Authorization:

- Demo database contains predefined users
- **Selected user:** Lyubimov (Administrator)
- With maximum permissions

---

#### Result:

- ✅ 1C:Accounting 8 installed successfully
- ✅ New information database created
- ✅ Started with demo data
- ✅ Logged into the system

Appearance:

- The 1C:Accounting 8 interface opens
