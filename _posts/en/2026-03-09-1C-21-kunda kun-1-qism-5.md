### 1. Interface structure (top to bottom)

| Area | Description | Elements |
|------|-------------|----------|
| **System commands** | Top area | Calculator, calendar, main menu, application info |
| **Sections panel** | Switch between sections | Grouped commands |
| **Section commands** | Actions for the current section | Document lists, catalogs |
| **Workspace** | Main data area | Tables, forms, reports |
| **Toolbar** | Additional functions | Search, history, favorites |

---

### 2. Toolbar functions

#### 2.1. History

```
Capabilities:
├── Navigation history by commands
├── Time indicator
├── Creation history of items
└── Quick jump: to the created item or document
```

#### 2.2. Favorites (Izbrannoe)

```
Usage:
├── Save any object with the ⭐ icon
├── Document lists (for example, "Goods receipt")
├── Reports (for example, "Inventory balances")
└── Specific documents can also be saved
```

---

### 3. Working with documents

#### 3.1. Creation methods

| Method | Path |
|--------|------|
| Method 1 | Documents list → "Create" button |
| Method 2 | Section → "Create" submenu → Required document |

#### 3.2. Document

```
Main fields:
├── Number (automatic)
├── Date (current date/time)
├── Organization
├── Warehouse
├── Currency
└── Supplier

Table part:
├── Item (select or open the catalog)
├── Quantity
└── Price
```

#### 3.3. Document statuses

| Status | Description |
|--------|-------------|
| **Saved** | Draft, unconfirmed |
| **Posted** | Operation executed, recorded in accounting |

> **Add to favorites:** Use the ⭐ button to save any document to the quick list.

---

### 4. Working with reports

#### 4.1. Opening

```
Path: Section → "Reports" submenu → Required report
```

#### 4.2. Drill-down (Decoding) — a strong point of 1C

```
Implementation:
1. Generate the report (for example, "Mutual reports reference")
2. Double-click the amount
3. Choose a drill-down option:
   ├── Drill down to document
   └── Other options
4. Result: Shows which documents produced the debt
5. Double-click a document row → open the document
```

> **Advantage:** You can drill down from the total in the report to a specific document.

---

### 5. Additional elements

| Element | Description |
|---------|-------------|
| **Close button** | Close unnecessary windows |
| **Forward/Back arrows** | Navigate between opened windows |
| **Table parts** | If multiple, shown as tabs |

---

### Main conclusion

The "Taxi" interface is intuitive, fast and flexible. Main working principles:

1. Single window — all operations
2. Favorites and history — quick access
3. Documents — simple creation and posting
4. Reports — powerful drill-down capabilities
