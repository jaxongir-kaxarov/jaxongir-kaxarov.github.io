## 1. Цель задания

Нужно создать новую конфигурацию для организации **КонцОптТорг**.

Эта конфигурация в дальнейшем будет использоваться для:

* управления бизнес‑процессами
* ведения торговых операций

На данный момент задача:

* создать **информационную базу**
* добавить необходимые **объекты конфигурации**.

---

## 2. Информация об организации

В системе:

* **1 юридическое лицо**
* **1 склад**

В будущем расширение не планируется.

Поэтому:

* **организация**
* **склад**

будут заданы через **константы**.

Эти данные далее будут использоваться в **печатных формах**.

Например:

* из какой организации выполняется **отгрузка**
* с какого **склада** отправлено

---

## 3. Создание новой информационной базы

Шаги:

* 1️⃣ открыть **список баз**
* 2️⃣ нажать **добавить**
* 3️⃣ выбрать **создание новой информационной базы**
* 4️⃣ выбрать **без конфигурации**

Имя базы:

```md
КонцОптТорг
```

Платформа:

**1С 8.3**

---

## 4. Открытие конфигурации

Запускается **Конфигуратор**.

Далее:

* через команды **конфигурация**
* **открыть конфигурацию**

открывается конфигурация.

---

## 5. Создание констант

Создаются две **константы**.

### 1️⃣ наименование организации

```md
НаименованиеОрганизации
```

* **тип данных → строка**
* **длина → 80 символов**

### 2️⃣ наименование склада

```md
НаименованиеСклада
```

Для создания второй константы можно:

* **Ctrl + C**
* **Ctrl + V**

чтобы скопировать константу.

---

## 6. Создание справочников

Создаются три **иерархических справочника**:

```md
Номенклатура
```

```md
Контрагенты
```

```md
Сотрудники
```

При создании включается опция:

**иерархический справочник**.

Остальные справочники создаются путём **копирования**.

---

## 7. Тип отношений для Контрагентов

Каждый **контрагент** может иметь следующие роли:

* **клиент**
* **поставщик**
* **прочие отношения** (банк, налоговая инспекция, учредитель)

---

## 8. Почему не использовано перечисление?

Изначально мог бы быть вариант:

**перечисление ТипОтношений**

Но есть проблема:

один **контрагент** может одновременно быть:

* **клиентом**
* **поставщиком**

Поэтому корректное решение:

использовать **булевы реквизиты**.

---

## 9. Реквизиты Контрагентов

В справочнике **Контрагенты** создаются следующие реквизиты.

### 1️⃣ клиент

**тип данных → булево**

### 2️⃣ поставщик

**тип данных → булево**

### 3️⃣ прочие отношения

**тип данных → булево**

Эти реквизиты отображаются в виде **флажков**.

---

## 10. Ответственный менеджер

Для каждого **контрагента** определяется ответственный **менеджер**.

Добавляется реквизит:

**ОтветственныйМенеджер**

**тип данных → справочник ссылка Сотрудники**

---

**F5**

---

## 14. Создание Сотрудников

В справочнике **Сотрудники** добавлены несколько сотрудников.

```md
Иванов
```

```md
Петров
```

Эти сотрудники будут использоваться для:

* **ответственный менеджер**
* **расчет заработной платы**
