## 1. What is Константы?

**Константы** is a **объект конфигурации** that stores a **single value**.

For comparison:

| Object            | Number of values         |
| ----------------- | ------------------------ |
| **справочник**    | many values              |
| **перечисление**  | several fixed values     |
| **константа**     | single value             |

---

## 2. What data are Константы used for?

**Константы** are typically used for:

* data that changes rarely
* or does not change at all

For example:

* organization name
* tax rate
* standard parameters

---

## 3. Creating a Новый константа

In **Конфигуратор** there is a special section to create constants:

**константы**

### Steps

* 1️⃣ Open the **константы** section
* 2️⃣ Create a new element
* 3️⃣ Enter the name:

```md
НаименованиеОрганизации
```

---

## 4. Choosing the Тип данных

Each **константа** has a **тип данных**.

By default the system suggests:

**строка (длина 10)**

But this is often not enough.

For example:

For **наименование организации**

10 characters is too short.

Therefore increase the length.

For example:

**80 символов**

---

## 5. Choosing the correct length

When selecting **Длина строки** consider:

❌ it should not be too small
❌ and not excessively large

For example:

* setting **800 символов** is not recommended

Reason:

* extra load on the system
* increase in database size

So choose a sufficient length.

---

## 6. Неограниченная длина

If the text can be very long:

**неограниченная длина**

can be selected.

In this case:

* the user can enter text of any length.

---

## 🛠 Пользовательский режим

After creating the constant restart the system.

* 1️⃣ Press **F5**
* 2️⃣ Open **пользовательский режим**

---

## 7. Entering the Константа value

A new menu appears in the interface:

**сервис**

Here you can enter the value of the constant.

For example:

**наименование организации**

value:

```md
ООО "МебельДомТорг"
```

---

## 8. Where are Константы used?

**Константы** are often used in:

* **печатные формы**
* **алгоритмы**
* **документы**

For example:

When printing a **товарная накладная**

you can show which organization the goods are shipped from.

For example:

**отгрузка идет от организации мебель дом торг**

This value is taken from the **константа**.
