## 1. What is a Перечисления?

**Перечисления** is a **configuration object** that stores a **list of predefined values**.

This list:

* is created in the **Конфигуратор**
* cannot be **modified by the user**
* cannot have new values added by users

---

## 2. Difference between Перечисления and Справочник

| Property                     | **перечисления**   | **справочник** |
| ---------------------------: | ------------------ | -------------- |
| Where values are created     | **Конфигуратор**   | user           |
| Adding new elements          | not allowed        | allowed        |
| Number of elements           | strictly fixed     | unlimited      |

Therefore:

* **перечисления** → for small and constant lists
* **справочник** → for large and changing lists

use appropriate.

## 3. Creating a new Новый перечисления

Now we will create a new **перечисления** in the **Конфигуратор**.

### Steps

* 1️⃣ Go to the **перечисления** section
* 2️⃣ Create a new element
* 3️⃣ Enter the name:

```md
ТипыТоваров
```

---

## 4. Adding values

Then, in the **данные** tab create the **допустимые значения**.

For example:

* **Товар**
* **Услуга**
* **Работа**
* **ВозвратнаяТара**

This completes the **типы товаров** list.

These values are:

* fixed
* predefined

---

## 5. Using Перечисления

Перечисления are often used as:

* the **тип данных** for **реквизиты**.

For example:

inside the **номенклатура** справочники.

---

## 6. Creating a new Новый реквизит

Now create a new реквизит inside the **номенклатура** справочники.

This time we will use a different approach.

In previous lessons we used the:

**окно редактирования объекта**

Now we will work via the:

**дерево конфигурации**

### Steps

* 1️⃣ Open the **номенклатура** справочники
* 2️⃣ Select the **реквизиты** section
* 3️⃣ Add a new реквизит

Name the реквизит:

```md
ТипТовара
```

---

## 7. Selecting the Тип данных

Now choose the **тип данных** for this реквизит.

The **выбор типа** window opens.

Select the following option:

**перечисление ссылка типы товаров**

This means:

the реквизит value will be chosen from the **типы товаров** перечисления.
