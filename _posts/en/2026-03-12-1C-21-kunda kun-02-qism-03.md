### 1. Steps to create the database

| Step | Action |
|------|--------|
| **Choosing the platform** | 1C:Enterprise 8.3 (educational version) |
| **Add database** | "Добавить" button |
| **Option** | Create a new database (not an existing one) |
| **Template** | Empty configuration (no ready-made template) |
| **Name** | "МебельДомТорг" |
| **Version** | 8.3 selected |

---

### 2. Run modes

| Mode | Purpose | Button |
|------|---------|--------|
| **User mode** | Run the application | "1C:Enterprise" |
| **Configurator** | Programming, setup | "Configurator" |

---

### 3. Features of the empty database

- Calculator
- Calendar (can view multiple months)
- Text documents
- Tabular documents (not Excel, no formulas)

**Important:** Users cannot enter data — a configuration is required!

---

### 4. Naming the configuration

| Property | Description | Rule |
|----------|-------------|------|
| **Name** | Identifier | No spaces, each word starts with an uppercase letter |
| **Synonym** | Name visible to the user | Spaces and quotes are allowed, write it clearly |

**Example:**

- Name: `МебельДомТорг`
- Synonym: `"ООО "Мебель Дом Торг""`

---

### 5. Quick run (Debugging)

| Action | Button | Result |
|--------|--------|--------|
| Save and run | `F5` | Configuration is saved + user mode opens |
| Save only | `F7` | Configuration is updated |

**Result:** The program title shows the synonym ("ООО "Мебель Дом Торг"").

---

### 6. Key concepts

| Term | Definition |
|------|------------|
| **Platform** | 1C:Enterprise 8.3 — the application platform |
| **Configuration** | User functionality (we create it) |
| **Typical solutions** | Ready-made commercial configurations (Accounting, Trade Management, etc.) |
| **Debugging (F5)** | Switching directly from the configurator to user mode |

---

### 7. Summary

- An empty database was created
- Name and synonym were assigned via the configurator
- A quick check was performed using F5
- Now configuration objects need to be created (catalogs, documents)
