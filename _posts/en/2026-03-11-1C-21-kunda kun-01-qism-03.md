### 2. Platform installation steps

#### 2.1. Download
- **Location:** v8.1c.ru
- **Path:** Main Menu → Methodical Support → Educational Version
- **Requirement:** Fill out a form in the online store (full name + email)
- **Result:** A download link is sent by email

#### 2.2. Extracting from the archive
- Large archive → extraction may take a long time
- Extracted to a folder

#### 2.3. Installation methods

| Method | Description |
|--------|-------------|
| Fully automatic | All components are installed |
| **Custom installation** | **Select required components** |
| Manual installation | Install from the "platform" folder |

> The course uses the **custom installation** method — only the platform was installed.

#### 2.4. Installation settings
- Install location: Default (C:\Program Files\1cv8)
- Interface languages: All languages or selected
- **Selected:** Russian only

---

### 3. Launching the application

**Path:** Start → All Programs → 1C:Enterprise 8.3 (Educational version)

**First window:** Database list
- Currently empty
- The first database will be created in upcoming lessons

---

### Main conclusion

The educational version is a free, fully functional platform intended for learning and testing. Installation is straightforward but time-consuming. The main work begins with creating a database.
