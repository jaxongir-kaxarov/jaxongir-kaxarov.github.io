* **справочники**
* **перечисления**
* **константы**

Эти объекты используются для **хранения и управления данными**.

## 2. Созданные справочники

В практической части созданы три **справочника**:

* **номенклатура**
* **склады**
* **контрагенты**

Также были изучены следующие возможности:

* **иерархические справочники**
* добавление **реквизитов**

---

## 3. Основные различия трёх объектов

### 3.1 Константы

**Константа** — это **самый простой объект**.

Характеристики:

* хранит только **одно значение**
* значение **задаёт пользователь**
* при необходимости значение можно получить через **встроенный язык**
* то есть можно использовать в **программном коде**

Например:

**наименование организации**

---

### 3.2 Перечисления

**Перечисления** — это **список заранее определённых значений**.

Характеристики:

* значения создаются в **Конфигураторе**
* пользователь **не может добавить новое значение**
* список **определяется разработчиком**

Например:

**типы товаров**

значения:

* **товар**
* **услуга**
* **работа**
* **возвратная тара**

---

### 3.3 Справочники

**Справочник** — это **наиболее гибкий объект**.

Характеристики:

* пользователь **может создавать новые элементы**
* может создавать **группы**
* если справочник **иерархический**, элементы располагаются внутри групп
* элементы можно **удалять**

То есть:

пользователю предоставляется **свобода действий**.

---

## 4. Возможности справочника

С элементами **справочника** можно выполнять следующие операции:

* создать новый **элемент**
* создать **группу**
* переместить элементы в **другую группу**
* **удалять** элементы
* удалять элементы из **информационной базы**
