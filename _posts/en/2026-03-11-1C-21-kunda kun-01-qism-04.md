### Installing the 1C:Enterprise 8.3 Platform

#### Reasons for choosing this version:

- Most users currently work with version 8.2
- The number of 8.3 users is growing day by day
- **Goal:** Focused on learning version 8.3

---

#### Available versions (technology distributives):

| Version | Release |
|---------|---------|
| 8.3     | 3.6.8.7 |
| 8.2     | 2.1.8.109 |

---

#### Problem:

- The official Russian site currently only offers 8.2
- The 8.3 version is not included in the archive (planned to be added later)

---

#### Solution:

**1C Developer Network (1cfdn.com)** - the English site

**Steps:**

1. Visit the site:
   - Go to 1cfdn.com

2. Register:
   - Go to the "Learning" section
   - Choose the "Building your First Application" link
   - "Download The Free 1C Enterprise Platform" → "Training version"
   - Click "Free Sign Up"
   - Enter information:
     - Login (for example: programmier1cv8)
     - Password
     - First and last name
     - Email
     - Captcha (verify not a robot)
   - Click "Sign Up"

3. Activate the account:
   - Open the email that arrives
   - Click the confirmation link

4. Download the platform:
   - Log in with your credentials
   - Go to the "Free Download" section
   - Select version 8.3.6.8.7
   - Download via the provided link

5. Installation:
   - Extract the archive (may take a few minutes)
   - Open the "1C Disc" folder
   - Run Autorun.exe or setup.exe
   - Choose "Custom Setup"
   - Select "1C:Enterprise 8.3 Training Version"

Features:

- The installer automatically detects the OS language
- Russian Windows → Russian installer

---

#### Result:

✅ The latest Russian-language 8.3 version was downloaded from the English site and installed
