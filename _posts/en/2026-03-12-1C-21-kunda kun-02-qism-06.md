## 📄 Short Description

In this lesson we create a new **справочник** called **Номенклатура** and learn to add additional **реквизиты** to it.

**Номенклатура** — the list of **товары** a company buys and sells. Inside this справочник additional fields are created to store information about a product, for example **Описание товара** and **основной поставщик**.

The lesson shows how to add new **реквизиты** via the **данные** tab, choose their **тип данных** and how to use this information in **пользовательский режим**.

---

## 📚 Full Notes

## 1. Create a new справочник

We will create a new **справочник**.

This will be a list of **товары**, meaning:

* goods purchased
* goods sold

Such a list is usually called:

**Номенклатура**

### Creation steps

#### 1️⃣ Click the **добавить** button

#### 2️⃣ Enter the name:

**Номенклатура**

---

## 2. Additional fields (реквизиты)

Inside the **Номенклатура** справочник we need to store extra information.

For example:

* product description
* main supplier

For this we create **реквизиты**.

Steps:

### 1️⃣ Open the **данные** tab

### 2️⃣ Add a new **реквизит**

---

## 3. Реквизит: Описание товара

First реквизит:

**ОписаниеТовара**

### Naming rules

In the **имя** field:

* no spaces
* no special characters

Only:

* letters
* numbers
* **_**

are allowed.

For example:

**Номенклатура**

But in the **синоним** field:

**Список товаров**

* any text can be entered

The user sees the **синоним** exactly.

### Important difference

| Field        | Who uses it    |
| -----------  | -------------- |
| **имя**      | developer      |
| **синоним**  | user           |

When writing code the developer refers to the **имя**.

---

## 4. Choose тип данных

Each **реквизит** requires a **тип данных**.

For **Описание товара** choose:

**тип данных → строка**

But the default length:

**10 символов**

is too small.

Options:

* set length to **100**
* or enable **неограниченная длина**

Correct choice:

✅ **неограниченная длина**

This allows the user to enter text of any length.

---

## 5. Second реквизит: основной поставщик

Create a new реквизит:

**ОсновнойПоставщик**

There is no space between the two words.

When you press Enter the system automatically sets the **синоним** to:

**Основной поставщик**

This happens because:

* the second word starts with a **capital letter**.

---

## 6. Choose тип данных

This реквизит needs a different data type.

In the Тип данных selection window the following options are available:

### Primitive types

* **число**
* **дата**
* **булево**

The **булево** type has only two values:

* **истина**
* **ложь**

Often this appears as a **checkbox**.

---

### Ссылочный тип данных

The option we need is:

**справочник ссылка**

Reason:

For **основной поставщик** an element from the **контрагенты** справочник is selected.

So choose:

**тип данных → справочник ссылка контрагенты**

This means the реквизит:

**links to an element in контрагенты**

```md
СправочникСсылка.Контрагенты
```

---

## 🛠 Пользовательский режим

Now start the system.

### 1️⃣ Press **F5**

### 2️⃣ Save the **конфигурация базы данных**

A new menu appears in the interface:

**список товаров**

This is actually the **Номенклатура** справочник.

The user sees the **синоним**.

---

## 7. Create a new product

Example:

```md
Cтол обеденный
```

### Description

**Описание товара**

for example:

```md
Длина = 120 см, высота = 70 см
```

---

## 8. Selecting Основной поставщик

The **основной поставщик** field has a special button.

When clicked:

* most used elements appear
* if not present click **показать все**

Then the **контрагенты** list opens.

For example:

select **поставщики → Мебель опт ООО**

---

## 9. Ссылочный реквизит capabilities

These реквизиты also have another button:

**открыть**

Using this button you can:

open the selected **контрагент** for direct **редактирование**.

---

## 10. Create another product

Second item:

```md
Cтол журнальный
```

### Description

```md
Cтекло
```

### Поставщик

Previously selected:

**Мебель опт ООО**

This time the system suggests it automatically.

Reason:

the system **remembers** user choices.

---

## 11. Save process

When an item is saved the system shows a:

* **всплывающее окно**

In this window the user can:

* reopen the item
* or continue
